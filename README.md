# FinFry — налоговый штурман в Германии

Веб-приложение, которое показывает всю вашу налоговую ситуацию в Германии на одном экране. Работает в браузере, без регистрации и без сервера.

**Открыть:** https://d-bridge-it.github.io/finfry/

## Что умеет

- **Обзор за год** — оценка возврата или доплаты, расчёт по шагам, средняя и предельная ставка, сроки, личные подсказки.
- **Доходы и расходы** — зарплата, фриланс, Gewerbe, капитал, аренда, пособия; расходы по немецким категориям (Werbungskosten, Betriebsausgaben, Sonderausgaben, § 35a и др.).
- **Документы** — фото чеков и PDF хранятся в браузере и привязываются к записям.
- **Помощник FinFry** — малёк золотой рыбки. Без настройки отвечает по встроенным правилам; с ключом Claude API понимает любые вопросы, читает чеки и сам записывает расходы.
- **Профиль** — расчёт подстраивается под человека: найм или своё дело, брак, дети, церковный налог, дорога, хоум-офис, Kleinunternehmer.
- **Резервная копия** — выгрузка и восстановление одним файлом, экспорт в CSV, отчёт для печати.

## Что считает

Einkommensteuer по § 32a EStG за 2024–2026 (Grundtarif и Splitting), Solidaritätszuschlag, Kirchensteuer, Abgeltungsteuer, Gewerbesteuer с зачётом по § 35, Umsatzsteuer и лимит Kleinunternehmer, Pendlerpauschale, Homeoffice-Pauschale, Arbeitnehmer-Pauschbetrag, Sonderausgaben, zumutbare Belastung, Kindergeld против Kinderfreibetrag, Progressionsvorbehalt, § 35a.

Модель упрощённая: без амортизации по годам, без точного разделения доходов супругов и без частных случаев. **Это оценка для ориентира, а не налоговая консультация.** Итог определяет Finanzamt.

## Приватность

Все данные лежат в IndexedDB вашего браузера и никуда не отправляются. Исключение — если вы сами вставите ключ Claude API: тогда вопросы и цифры (без имени) уходят в Anthropic для ответа. Ключ хранится только в вашем браузере.

## Разработка

Чистый HTML/CSS/JS без сборки. Запуск локально: `python -m http.server` в папке проекта. Проверка налогового движка: `node selftest.mjs`. Параметры по годам — в `tax.js` (`PARAMS`).
